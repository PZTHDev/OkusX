# ไทย

โปรแกรมรวมคลังเกม Steam จากหลายบัญชีเข้าด้วยกัน แบบ **Standalone** เก็บไฟล์ทุกอย่างไว้บนเครื่องของผู้ใช้เอง ไม่มีการฝังมัลแวร์ และ **ไม่บังคับให้ล็อกอินผ่านตัวโปรแกรม OkusX**

> สถานะ: **เบต้า 1.0** ยังมีส่วนที่ไม่เสถียร ใช้งานได้ แต่อาจเจอบั๊ก

## ฟังก์ชัน

1. **กดโหลดเกมและเล่นเกมได้เลย** โดยไม่ต้องสลับบัญชีเอง โปรแกรมจะสลับไปยังบัญชีที่มีเกมนั้นให้ทันที ถ้ามีหลายบัญชีที่มีเกมซ้ำกัน เลือกได้ว่าจะเข้าบัญชีไหน
2. **สลับบัญชีได้ในตัว** ไม่จำเป็นต้องกดเล่นหรือโหลดเกม กดสลับบัญชีได้ทันที
3. **ตกแต่ง UI ได้ตามต้องการ** ธีม สี ฟอนต์ พื้นหลัง (ภาพ/GIF/วิดีโอ) และสติกเกอร์
4. **รองรับ 2 ระบบ: Steam และ Epic** และจะเพิ่มระบบอื่นในอนาคต
5. **กิมมิกเล็กๆ:** เล่นเพลงและคลิปได้ในโปรแกรม (Spotify / YouTube)
6. **ตอนติดตั้งเลือกได้ 3 ระดับการประหยัดเครื่อง** (ประหยัด / พื้นฐาน / เต็ม) ยังไม่เสถียรมากนัก แต่เพียงพอให้รันได้ลื่น
7. **ดูส่วนลดและเกมแจกฟรี** จาก Steam Store และ Epic Store (เกมแจกต้องกดรับเอง และบางครั้งต้องพิมพ์ชื่อเกมค้นหาเองเมื่อคลิกเกมแล้วเปิดหน้าต่างขึ้นมา)
8. และฟังก์ชันอื่นๆ ที่ไม่ได้กล่าวถึง เช่น เพิ่มเกมเองจากไฟล์ exe, หน้าเกมพร้อมคลิป/ภาพ/แท็ก/รีวิว

## วิธีใช้งาน

**ติดตั้ง**
ติดตั้งโปรแกรมแล้วเลือกที่อยู่ไฟล์ของ Steam และ Epic ไม่ต้องกังวล ทุกอย่างถูกเซฟไว้บนเครื่องของคุณเท่านั้น

**Steam**
- ถ้าเลือกที่อยู่โฟลเดอร์ Steam ถูกต้อง บัญชีของคุณจะโผล่ขึ้นมาอัตโนมัติ และสลับบัญชีได้ในแถบบัญชี
- ต้องกด **"ดึงรายชื่อเกม"** ที่มุมขวาของหน้าจอก่อน โปรแกรมถึงจะดึงเกมมาให้
- บัญชีที่ตั้งเกมเป็น **ส่วนตัว (Private)** จะไม่ถูกดึงมาให้ ต้องทำอย่างใดอย่างหนึ่ง:
  1. ล็อกอินด้วยรหัสของคุณเองผ่านหน้าล็อกอิน Steam จริง หรือ
  2. ตั้ง Game details ของบัญชีนั้นเป็น **สาธารณะ (Public)** ด้วยตัวเอง (ปิดกลับได้ภายหลัง)

**Epic**
- ยังไม่สมบูรณ์มากนัก แต่ระบบสลับบัญชีใช้งานได้เกือบทั้งหมด
- ต้องกด **"เพิ่มบัญชี"** และล็อกอินก่อน ระบบถึงจะทำงาน

**ระบบเพลง**
- ล็อกอิน Spotify ผ่านปุ่มล็อกอินในโปรแกรม เราไม่ได้เก็บรหัสผ่านของคุณ แต่จะจำสถานะว่าคุณเข้าสู่ระบบแล้ว เพื่อเล่นเพลงได้ทันที

## ความเป็นส่วนตัวและความปลอดภัย

- โปรแกรมไม่เห็นและไม่เก็บ **รหัสผ่าน** ของ Steam, Epic หรือ Spotify การล็อกอินทำในหน้าเว็บทางการ
- ข้อมูลของโปรแกรม (คลังเกม, ค่าตั้งค่า, ธีม) เก็บบนเครื่องคุณเท่านั้น ไม่อัปโหลดขึ้นเซิร์ฟเวอร์
- การล็อกอินบัญชี Private ของ Steam ใช้ token ในหน่วยความจำชั่วคราว ไม่เก็บลงไฟล์
- **การสลับบัญชี Epic และการจำสถานะล็อกอิน Spotify** ทำโดยเก็บ session ของการล็อกอินไว้ **ในเครื่องของคุณ** (ไม่ได้ส่งออกไปที่ใด) session นี้เหมือนการ "จำฉันไว้" ของแต่ละบริการ ใครเข้าถึงโฟลเดอร์ข้อมูลของโปรแกรมบนเครื่องคุณได้ ก็อาจใช้ session นั้นได้ จึงควรล็อกเครื่องและไม่แชร์โฟลเดอร์ข้อมูลโปรแกรม ปุ่ม "รีเซ็ตข้อมูลบัญชี" ลบ session เหล่านี้ได้
- ถ้าคุณไม่ใส่ Steam API Key ของตัวเอง โปรแกรมจะส่ง **SteamID** (รหัสสาธารณะของบัญชี) ผ่านเซิร์ฟเวอร์กลางแบบ pass-through เพื่อถาม Steam ว่าบัญชีนั้นมีเกมอะไร (ได้เฉพาะบัญชี Public) ถ้าไม่ต้องการ ให้ใส่ API Key ของคุณเองในตั้งค่า โปรแกรมจะเรียก Steam ตรง
- โปรแกรม **อ่านไฟล์ของ Steam อย่างเดียว** ไม่แก้ไขหรือลบ

## ข้อจำกัด

- เกมที่ได้จาก **Family Sharing** จะไม่แสดงในบัญชีที่ยืม
- บัญชีที่เป็น **Private** ต้องล็อกอินหรือเปิดเป็น Public ก่อนจึงจะดึงเกมได้ (Steam ไม่มีทางอื่น)
- วิธีล็อกอินเพื่อดึงบัญชี Private ใช้ endpoint ที่ **ไม่ใช่ API ทางการของ Steam** อาจเปลี่ยนหรือใช้ไม่ได้ในอนาคต
- **Epic ไม่มี API สาธารณะ** สำหรับอ่านคลังเกม จึงไม่สามารถดึงคลังเกม Epic ของบัญชีมาให้อัตโนมัติ และระบบสลับบัญชี Epic อาจพังเมื่อ Epic Launcher อัปเดต
- การสลับบัญชี Steam ต้อง **รีสตาร์ท Steam** ถ้ามีเกมกำลังรันอยู่ ควรปิดก่อน
- บัญชีที่ไม่ได้ติ๊ก "จดจำรหัสผ่าน" ใน Steam จะต้องกรอกรหัสผ่านเองเมื่อสลับ และอาจมี Steam Guard
- ต้องมีอินเทอร์เน็ตสำหรับปกเกม ข้อมูลเกม ร้านค้า และส่วนลด
- ปกเกมถูกโหลดเก็บในแรมเท่านั้น (ไม่เซฟภาพลงดิสก์) เปิดโปรแกรมใหม่จึงต้องโหลดปกใหม่
- พื้นหลัง GIF/วิดีโอและสติกเกอร์เคลื่อนไหว ใช้แรมและ CPU มากกว่าภาพนิ่ง ควรใช้โหมดประหยัดบนเครื่องสเปกต่ำ
- ข้อมูลเกมและการจับคู่เกมที่เพิ่มเอง อาจไม่ตรงเสมอไป ตรวจและแก้ไขได้เอง
- ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล Windows SmartScreen หรือโปรแกรมแอนติไวรัสบางตัวอาจขึ้นเตือน
- รองรับเฉพาะ Windows
- ฟังก์ชันบางอย่างยังเป็นเบต้า อาจมีบั๊กและเปลี่ยนแปลงได้

## ความต้องการของระบบ (Requirements)

- Windows 10 หรือ 11
- .NET Framework 4.8
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (มีใน Windows 11 อยู่แล้ว Windows 10 บางเครื่องต้องติดตั้งเอง) ใช้สำหรับหน้าล็อกอินและตัวเล่นคลิป
- Steam ติดตั้งในเครื่อง (สำหรับฟังก์ชัน Steam) และ Epic Games Launcher (สำหรับฟังก์ชัน Epic)

- พื้นที่ดิสก์ ~5 MB สำหรับตัวโปรแกรม (ธีมเสริมแยกต่างหาก)
- แรมที่ใช้งานโดยทั่วไป ~100-200 MB (มากขึ้นถ้าใช้วิดีโอ/GIF พื้นหลัง)

# English

A **standalone** tool that merges your Steam libraries from multiple accounts into one. Everything is stored locally on your own PC, there is no bundled malware, and **you are never required to log in through OkusX itself**.

> Status: **beta 1.0**. It works, but some parts are not stable yet and you may run into bugs.

## Features

1. **Install and play without switching accounts yourself.** OkusX switches to the account that owns the game for you. If several accounts own the same game, you choose which one to use.
2. **Built-in account switcher.** You can switch accounts at any time, without having to launch or install a game.
3. **Customizable UI:** themes, colors, fonts, backgrounds (image / GIF / video) and stickers.
4. **Two platforms supported: Steam and Epic**, with more planned.
5. **Small extras:** play music and clips inside the app (Spotify / YouTube).
6. **Three resource-saving levels at install time** (Space saver / Basic / Full). Not very stable yet, but good enough to run smoothly.
7. **Discounts and free games** from the Steam Store and the Epic Store. Free games must be claimed by you, and sometimes you need to type the game name into the search yourself after clicking a game and the window opens.
8. **Other features not listed here,** such as adding custom games from an exe, and a game page with clips, screenshots, tags and reviews.

## Usage

**Install**
Run the installer and point it to your Steam and Epic folders. Don't worry: everything is saved on your own machine only.

**Steam**
- If you choose the correct Steam folder, your accounts show up automatically and you can switch accounts from the accounts bar.
- Press **"Fetch game lists"** (top right of the screen) first; OkusX only loads games after that.
- Accounts whose game details are **Private** will not be fetched. Do one of the following:
  1. Sign in with your own credentials through the real Steam login window, or
  2. Set that account's Game details to **Public** yourself (you can set it back to Private afterwards).

**Epic**
- Not fully polished yet, but account switching works almost all the time.
- You must press **"Add account"** and log in first before it works.

**Music**
- Log in to Spotify with the in-app login button. We don't store your password; OkusX only remembers that you are signed in, so you can play music right away.

## Privacy and security

- OkusX never sees or stores your **passwords** for Steam, Epic or Spotify. Logins happen on the official web pages.
- App data (library, settings, themes) stays on your PC and is not uploaded.
- Private-profile fetching for Steam uses a token held in memory only and never writes it to disk.
- **Epic account switching and the remembered Spotify sign-in** work by keeping the login session **on your own PC** (nothing is sent anywhere). It behaves like a "remember me" on each service. Anyone with access to OkusX's data folder on your computer could potentially use those sessions, so lock your PC and don't share that folder. The "Reset account data" button removes these sessions.
- If you don't enter your own Steam API key, OkusX sends the account **SteamID** (a public identifier) through a simple pass-through proxy to ask Steam which games the account owns (public profiles only). If you prefer not to, enter your own API key in settings and OkusX will call Steam directly.
- OkusX only **reads** Steam's files and never modifies or deletes them.

## Known limitations

- **Family Sharing** games do not appear under the borrowing account.
- **Private** accounts need a login or a temporary switch to Public before games can be fetched (Steam offers no other way).
- Logging in to fetch private libraries relies on endpoints that are **not official Steam APIs** and may change or stop working.
- **Epic has no public API** for reading libraries, so Epic libraries are not fetched automatically, and Epic account switching may break when the Epic Launcher updates.
- Switching Steam accounts **restarts Steam**; close any running game first.
- Accounts without "Remember password" enabled in Steam will ask for a password (and maybe Steam Guard) when switching.
- An internet connection is needed for covers, game info, stores and discounts.
- Covers are kept in RAM only (never saved to disk), so they reload each time you open the app.
- GIF/video backgrounds and animated stickers use more RAM and CPU than still images; use the saver mode on low-end PCs.
- Game info and matching for custom games may be wrong sometimes; you can review and correct it.
- The installer is not code-signed, so Windows SmartScreen or some antivirus programs may show a warning.
- Windows only.
- Some features are still beta and may have bugs or change.

## Requirements

- Windows 10 or 11
- .NET Framework 4.8
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (included with Windows 11; some Windows 10 PCs need to install it) - used for the login window and clip player
- Steam installed (for Steam features) and Epic Games Launcher (for Epic features)
- Internet connection
- About 5 MB of disk space for the app (optional theme downloads are separate)
- Typical RAM use ~100-200 MB (more with video/GIF backgrounds)

## Install

Download `OkusX.Setup.exe` from the [Releases](../../releases) page. It installs per user (no admin rights needed).
If Windows shows a SmartScreen warning because the installer is not code-signed, click **More info > Run anyway**.
